# BGen — слайды презентации

## Формат
- 9 слайдов
- 3-5 минут
- Живое демо обязательно

## Слайд 1 — Титул
- BGen
- ИИ-генератор браузерных игр по текстовому промпту
- Лого: 🎮
- Подзаголовок: «Один промпт — одна играбельная игра»

## Слайд 2 — Проблема
- Сегодня мини-игра = разработчик + дизайнер + тестировщик
- В WebView приложений нужны быстрые вовлекающие механики
- Аудитории разные: от детей до бабушек
- Текущее решение: зашитые шаблоны, скучно и не масштабируется

## Слайд 3 — Решение
- Промпт «замути змейку для бабушки» -> играбельная игра
- За 5-10 секунд
- В любом WebView (Telegram Mini App, приложение Билайна)
- Визуальная схема пайплайна

## Слайд 4 — Демо #1
- Живая генерация
- `замути змейку для бабушки`
- Показать крупный UI, простоту
- Поиграть 10-15 сек

## Слайд 5 — Демо #2
- Итерация: `сделай поле больше и добавь еду разных цветов`
- Обновлённая игра
- Проговорить: пользователь не программист

## Слайд 6 — Демо #3
- Другой жанр: `кликер с котиками для детей`
- Яркие цвета, эмодзи
- Доказательство: не шаблон, а генерация

## Слайд 7 — Архитектура
- Схема (из ARCHITECTURE.md)
- Ключевые блоки:
  - Classifier (эвристики)
  - Compiler (промпт из блоков)
  - Router (Claude/OpenAI/Ollama)
  - Analyzer (20+ инвариантов)
  - Repair loop
  - Corpus (few-shot)
  - Cache

## Слайд 8 — Что внутри
- Zero-deps ядро
- Итеративная доработка
- Адаптация под ЦА
- История и галерея
- Telemetry: latency, cache hits, repairs
